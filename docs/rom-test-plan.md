**验证顺序应能够定位失败发生在哪一层。**

1. 锁定 EmulatorJS 4.2.3 与兼容 FCEUmm 产物，记录每个核心文件摘要；不混入预发布版文件。
2. 在电脑浏览器用原始 ROM 打开独立播放页，检查运行日志及 Mapper 判定、首画面、方向/A/B/Start/Select 输入和声音。
3. 游玩并保存一个即时状态，改变画面状态后恢复；刷新页面再恢复；证明恢复的是运行状态，而非重新开局。
4. 若原始文件启动失败，在相同前端版本下换 Nestopia 对照，并标注核心差异；对比前不将失败归因于 ROM 损坏。
5. 电脑验证通过后，测试 Android/iOS 微信浏览器，再单独测试小程序 web-view；三种环境分别记录，结果不互相替代。
6. 完成 20 分钟持续游玩、重复进出和存档恢复，形成 G0/G1 结论后再推进完整后台。
